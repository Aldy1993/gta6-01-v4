Port Solano adalah game open-world kriminal ala GTA 6 yang berjalan di browser dari static files: kota pelabuhan orisinal, protagonis Rico Vega, 3 misi berantai, traffic dan pejalan kaki AI, polisi AI dengan wanted level, combat, HUD dengan minimap hidup, side gig Solano Packages, save/load, dan suara WebAudio sintetis.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Buka http://localhost:8080 di desktop Chrome.
